Read first: CLAUDE.md, channels/noor-e-raah/RULES.md (1, 2, 2c, 2d, 3 Munshi), brand/STYLE_NOOR.md section 6, shorts_queue.json, log.md (last 30 lines), shared/pricing.json.
Never publish (private only). Hard cap Rs 20 actual (GST incl.) per Short, balance floor Rs 50; free first, paid only after free quota (log why). No Prophet/Sahabi/Quran-named person/angel; no Allah depiction/voice.
Reference implementation (already worked): stories/006_imaan-shorts/short/ (gen_v3.py images, tts_v3.py voices, talk.py mouth-animation, build_v3.py video).

Steps (one story per run; if today's Short is already uploaded, stop):
1. Pick the first `planned` item of shorts_queue.json (n, key, theme). New folder stories/<NNN>_imaan-<key>/ (NNN = next free number after the highest in stories/). Copy `short/` scripts from 006 (gen_v3.py, tts_v3.py, talk.py, build_v3.py) and edit them for the new story (paths use the file location).
2. Script (free): a warm motivational Islamic story, AT LEAST 60 s (about 10-13 spoken lines, 4-7 s each), 2-4 characters who speak in first person (no narrator), cute (huge glossy eyes, round faces), ends with a clear lesson. One ayah may be used only if it fits: its Arabic = exact Tanzil bytes (download https://tanzil.net/pub/download/index.php?quranType=uthmani&outType=txt-2&agree=true), whole ayah, source line on screen. A hadith only if sahih with source. Write short/lines_v3.json (n, img, who, voice, text, style) + script.md. Run the Munshi subagent on the script (Arabic bytes, no Prophet/Sahabi, lesson, >= 60 s by TTS estimate); fix and re-review until PASS.
3. Images (free): scripts/cf_image.py style from gen_v3.py: each character once, then expression variants with input_image_0 = that character's first image (keeps the face). Close-up, front-facing, mouth closed. Check with MediaPipe that a face is found (talk.Talker) and that every character looks the same across variants. CF quota exhausted -> try again later in the run; paid Gemini image only if still impossible and within Rs 20.
4. Voices: tts_v3.py (free key first; paid fallback is automatic). Different voice per character (Leda girl, Gacrux grandmother, Charon man, Sulafat woman, Puck boy ... check audio sounds right via Whisper text check; a missing word = redo the line).
5. Full-motion + build (user 2026-11-09: "full-motion bhi try"):
   a. RIGHT AFTER the images exist (before voices), write short/motion.json (one entry per shot: n, img, an explicit motion sentence such as "she sighs, lowers her head, blinks twice", seed) and run `python scripts/ltx_kaggle.py push <story dir>` (free Kaggle T4, 73 frames, ~10 min per clip, ~4 min load; the queue can stall). Never block on it.
   b. Do voices (step 4) and the guaranteed version: build_v3.py -> short/imaan_short_<NN>.mp4 (mouth-animation, >= 60 s, -14 LUFS).
   c. Then check `python scripts/ltx_kaggle.py status <story dir>`; wait at most until 90 min after the push (poll every 10 min, never busy-loop). If COMPLETE: `fetch`; if EVERY shot<N>.mp4 exists and shows a stable face (compare MediaPipe landmarks / look at frames; identity drift or a mouth wide open = drop that clip) copy short/build_v4.py logic (per-frame landmarks + audio-driven mouth on the LTX clips) and build the FULL-MOTION version; use it instead of the mouth-only one. Missing/failed clips -> keep the mouth-only version (shots without a clip can be mixed: use the still + mouth anim for those shots).
6. Munshi final check on the video (frames, Arabic == Tanzil, subtitles safe area, no cut sentence, <= Rs 20, name_guard). BLOCKER -> fix free and recheck.
7. Upload PRIVATE with tools/youtube_upload.py for channel noor-e-raah (see skill youtube-publish; api_audited false -> private + STUDIO ACTION note). Title: <hook in Hindi> | Noor-e-Raah (no reference-video wording). Description: lesson, source of any ayah/hadith, "AI-generated animation and voice". contains_synthetic_media = true. Add to playlist imaan_shorts (PLdhrP4DE-lC8) via tools/yt_playlist.py patterns / playlistItems.insert.
8. Log: channels/noor-e-raah/log.md (story, cost, video id, STUDIO ACTION: set public yourself), shorts_queue.json status=uploaded, cost with scripts/story_budget.py. Sync: powershell -NoProfile -ExecutionPolicy Bypass -File tools\sync.ps1 -Message "noor short <NN>: uploaded private". Stalls: do not wait more than 2 hours for any one step; if a step cannot be done, write the reason in log.md and stop.
