# Ucharan (Arabic -> Devanagari) — Surah Al-Fil 105 | Khoji, 2026-11-14

Format (RULES 1c): each jumla block gets one `UCHARAN` line = the SAME Arabic words in Devanagari, read plainly by the narrator (NOT tilawat), shown under the Arabic. Kalam finalises. Tags [U1]-[U10] = one per jumla.

**Sources:** Arabic = Tanzil Uthmani bytes (dossier 1.1; sha256 pending on PC). Latin check = Tanzil `ara-quran-la` (`translit_tanzil`) and quran411 `ara-quran-la1` (`translit_q411`), both read 2026-11-14 (fact T3).

**Rules (as 003-007):** ق=क़ · ف=फ़ · غ=ग़ · خ=ख़ · ذ/ز/ض=ज़ · ث/ص/س=स · ع = vowel only (hamza/'ayn between vowels shown as अ) · article joins as pronounced · last vowel dropped at the jumla end (waqf; tanween dropped) · ا۟ not read.

**Points to check:**
(1) 105:1 `أَلَمْ تَرَ كَيْفَ فَعَلَ رَبُّكَ` Tanzil "Alam tara kayfa faAAala rabbuka", Q411 "Alam tara kaifa fa'ala rabbuka" -> **अलम तरा कैफ़ा फ़अला रब्बुक** (jumla-ant par kasra/fatha giri). `بِأَصْحَٰبِ ٱلْفِيلِ` Q411 "bi ashaabil feel" -> **बि अस्हाबिल फ़ील** (khanjari alif = आ; ص here = स; "hab" ke bajaye `ص-ح-ب`: अस्हाब).
(2) 105:2 `ضَ` in "tadleel": Q411 "tad leel" uses d; Hindi/Urdu convention ض = ज़ -> **तज़्लील** (Munshi/user: "तद्लील" ya "तज़्लील"; ek tay karo, hum ज़ lete hain). `يَجْعَلْ` Q411 "yaj'al" -> **यज्अल**; `كَيْدَهُمْ` -> **कैदहुम**; `فِى` alif maksura = ee -> **फ़ी**.
(3) 105:3 `وَأَرْسَلَ` -> **व अर्सला**; `عَلَيْهِمْ` -> **अलैहिम**; `طَيْرًا` Q411 "tairan" -> **तैरन** (tanween mid-ayah kept as "न"); `أَبَابِيلَ` -> **अबाबील** (kasra-ya long ee; fatha dropped at waqf).
(4) 105:4 `تَرْمِيهِم` Q411 "Tar meehim" -> **तरमीहिम**; `بِحِجَارَةٍ مِّن` tanween before meem merges: Q411 "jaaratim min" -> **बि हिजारतिम मिन**; `سِجِّيلٍ` shadda on jeem -> **सिज्जील** (tanween dropped).
(5) 105:5 `فَجَعَلَهُمْ` Q411 "faja 'alahum" -> **फ़जअलहुम**; `كَعَصْفٍ مَّأْكُولٍۭ` Q411 "ka'asfim m'akool" -> **कअस्फ़िम मअकूल** (`مَّأْكُولٍۭ`: Q411 "m'akool"; the preceding tanween merges into the shadda-meem so "कअस्फ़िम" + "मअकूल"; the small iqlab meem at the end is waqf: dropped).
