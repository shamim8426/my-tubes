# Ucharan (Arabic -> Devanagari) — Ayatul Kursi 2:255 | Kalam, 2026-10-30

Format decision (user 2026-10-30): each jumla (`[AYAH 2..11]`) gets one `UCHARAN` line = the SAME Arabic words in Devanagari, read plainly by the Ustaad (NOT tilawat) and shown under the Arabic on screen. This file lets Munshi check every chunk.

**Sources:** Arabic = Tanzil Uthmani (sources.json `ayah.text`, copied from script by code). Latin check text = Tanzil transliteration, edition `ara-quran-la` (fawazahmed0/quran-api, source tanzil.net) = column 2; cross-check with quran411 (`ara-quran-la1`, fawazahmed0/quran-api) for the jumla-end (waqf) forms. The Latin text is used ONLY to check consonants/vowels; it is not shown or spoken, and the Devanagari is our own writing. Recorded in sources.json as `TRANSLIT_TANZIL`, `TRANSLIT_Q411`, fact `T3`.

**Rules used:** ق=क़ · خ=ख़ · ذ/ظ/ض=ज़ · ف=फ़ · ع = the vowel only (अ/इ/उ, no special sign) · small final long vowel kept inside a jumla (लहू, इल्मिही) · at the END of a jumla the last vowel is dropped (waqf): हुव, नौम, अर्ज़, इज़्निह, शा, अज़ीम · the Arabic article joins the next word as pronounced (अल हय्युल, अल्लज़ी, अस्समावाति).

Check done by code: every Latin chunk joined == the Tanzil Latin tokens of that jumla (50/50 words); jumla pieces joined == the whole ayah.
