# Image requests for Noor-e-Raah History videos (Claude -> ChatGPT)

Claude writes what it needs in `REQUESTS.md`. ChatGPT reads it, creates the images and uploads them to `inbox/`. Claude then reads `inbox/` and uses them.

## Rules for every image (ChatGPT, please follow)
- Size/format: 16:9 landscape, 1920x1080 or larger, PNG (or JPG). No text, no logos, no watermark, no borders.
- File name: exactly the ID from REQUESTS.md, e.g. `R01_bazaar_day.png`. Variants: `R01_bazaar_day_b.png`.
- Look: polished cinematic 3D-illustration film still, ultra sharp, high contrast, deep rich saturated colours, clean clear air. Day looks like day, night looks like night. NO haze, fog, mist, dust clouds, bloom, washed-out whites.
- Period: 7th-century Madinah/Makkah. Mud-brick and palm-trunk houses, palm-leaf roofs, camels, horses, wool/linen robes, turbans, clay pots, oil lamps. No modern objects (no glass windows, steel, plastic, electric light, modern roads or signs).
- People: many people in crowd scenes, women included (long robes, headscarves), seen from behind or far away. NEVER a clear front face or portrait. Never show the Prophet (peace be upon him) in any form; no Sahaba portraits. No faces in foreground.
- Anatomy: every person has exactly two arms and two hands with five fingers each, two legs. No extra/merged limbs.
- Keep a calm foreground-midground-background depth (we animate it with parallax), clear subject, space on the lower third for subtitles.

## After uploading
Add one line to `inbox/DELIVERED.md`: `R01 done` (or a note if something differs). Claude marks used ones in REQUESTS.md.
