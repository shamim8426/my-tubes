# Great Dying (video 002): images to generate with ChatGPT (27 images)

Channel: Possibilities (`channels/reality-check`). Folder: `stories/002_great-dying/chatgpt_images/`.

## How to use
1. Open ChatGPT image generation. For EVERY image paste the **STYLE** block below first, then the line's prompt.
2. Ask for **one image per prompt**, wide **16:9 landscape** (1920x1080 if possible; at least 1536 px wide).
3. Save each image as `images/L<line number>.png` (or .jpg), for example `images/L058.png`. The number is the script line in the table. One file per line, do not rename.
4. Commit the files in `images/` to git. The build will pick them up (depth parallax, camera moves, label "AI reconstruction").

## STYLE (add to every prompt)
> Photorealistic cinematic documentary still, natural light, balanced mid-tone exposure (not dark, not washed out), rich realistic detail, shot on a 35mm lens, gentle atmospheric haze, wide 16:9 frame. **No text, no letters, no numbers, no logos, no watermarks, no people, no faces.** One single image, not a collage (unless the prompt says split view).

## Rules
- No text or labels inside the picture (we add labels in the edit).
- No people or faces. Animals are fine (realistic reconstruction, wildlife-documentary look).
- Keep the same realistic look across all 27 so they match each other. Avoid cartoon, 3D-render or painterly looks.
- Do not copy a real artist's or studio's style by name.
