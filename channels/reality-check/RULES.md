# Channel RULES — Reality Check - Asli (reality-check)

Only the rules special to this channel. Read `shared/RULES.md` first; everything there applies here too.
- Channel RULES can be stricter than shared RULES, never looser. Copyright, channel ID, secrets and upload safety can never be relaxed by a channel.

## Facts and sources (stricter)
- Every claim in a script has a fact ID `[F#]` in the dossier with 2+ reliable sources (primary first). No source = the line is cut or marked as opinion/unknown.
- Munshi runs FACT CHECK (RULES 16) on every script before approval and again on the final subtitles.
- The video description lists the sources. A wrong fact found after upload: pinned correction + fix in the description the same day, log it in log.md.

## Topics and format
- Movies are a research signal only, never the video format. No movie clips, posters, dialogue or music.
- Start with science. No politics / hot controversies. Widen topics only after ~10-15 videos (user decision).
- Long 18-20 min (target), Shorts max 40 s. First 30 s hook, new question/reveal every 2-3 min.

## Budget
- Per-video cap for an 18-20 min Long is NOT set yet (the Jugnu Rs120 cap does not fit). Until the user sets it: free sources only, no paid call.

## Metadata
- Title carries the real search word of the concept; suffix `| Reality Check - Asli`. Description lists sources.
- `contains_synthetic_media`: true (AI voice/visuals) in channel.json; declare it at upload.
- The uploader's channel-ID check stays on (this channel shares the YouTube channel ID with the paused jugnu-stories).
