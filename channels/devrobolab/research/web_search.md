Facts (each step checked on S1 text captured by raw/capture.py):
1. Turn on in a chat: click "+" button in the lower left corner of the chat window -> find "Web search" in the dropdown and click -> a checkmark appears next to "Web search" when enabled. (S1)
2. Turn off: click "Web search" again. (S1)
3. Every response includes citations so you can verify sources yourself; response has direct citations, source links, relevant quotes. (S1; S2 "cited information")
4. Available globally on all Claude plans (S2 update 2025-05-27). S1: free users have usage limits that reset every five hours; web search and fetch both contribute to these limits.
5. Team/Enterprise: Owner or Primary Owner must first enable web search for the workspace in Organization settings > Capabilities. (S1)
6. New Claude experience: no web search toggle, Claude searches the web when it helps. (S1)
7. Tips: ask about recent information; to be sure, include "Search the web" or "Use web search" in the prompt; request multiple sources; verify important information. (S1)
