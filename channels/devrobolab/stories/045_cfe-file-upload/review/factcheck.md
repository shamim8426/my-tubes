# Fact check: Claude Feature 04 Short (045), Upload files to Claude (2026-11-07)
Source (official): https://support.claude.com/en/articles/8241126-upload-files-to-claude (own Playwright capture, raw/article.png)

| Claim in the video | Official page says | Result |
|---|---|---|
| Click the plus button in the chat box, choose "Add files or photos", pick the file | "Click the '+' button in the lower left corner of the chat box"; "Select 'Add files or photos' from the menu"; "Choose files from your device" | PASS |
| Drag and drop also works | "...or drag and drop the files directly into the chat window" | PASS |
| PDF, Word, CSV, text and photos work | Documents: PDF, DOCX, CSV, TXT, ...; Images: JPEG, PNG, GIF, WebP | PASS |
| Up to 20 files in one chat | "Number of files: Up to 20 files per chat" | PASS |
| PDFs up to 100 pages: charts and pictures are read too | "Claude analyzes both text and visual elements (like images, charts, and graphics) in PDFs of 100 pages or fewer" | PASS |
| Bigger PDFs: text only | "For PDFs from 101 to 1000 pages, Claude processes text only" (over 1000 pages cannot be uploaded; not said in the video) | PASS |
| Use the PDF viewer page number, not the printed one | "use the PDF page numbers as shown in your PDF viewer, not the page numbers printed on the document itself" | PASS |

Not claimed: Excel (needs code execution + file creation), size limits (500 MB), image sizes. The app screen (dark UI) and the PDF viewer are our own illustrations (labelled "Illustration" where an app screen is shown).
