## 1. Facts (official page only: support.claude.com, "Use Claude's chat search and memory to build on previous context")
- F1 Claude saves memory as small TOPICS while you chat; you can also say "remember this".
- F2 On by default for Free, Pro, Max, Ultra (web, Desktop, mobile apps; update the app). Team/Enterprise: the owner decides.
- F3 Switch: **Settings > Your Claude** (older layout: Settings > Memory), toggle **Generate memory from chats**. Two choices: **Pause memory** (keeps old, stops using/making) and **Reset memory** (deletes ALL, cannot be undone).
- F4 One chat without memory: new chat, click "+", turn Memory off BEFORE the first message (cannot be changed later).
- F5 It remembers work and everyday context (role, projects, preferences). Sensitive topics (health, religion, politics) are NOT saved by default; ID numbers, financial account numbers etc. are never saved, even if you ask.
- F6 See / edit / delete: Settings > Your Claude > **Manage** next to **Your memory** > list of **Topics** > read, edit icon, or **Delete**. Or tell Claude in chat what to remember / change / forget (applies from the next chat).
- F7 **Incognito**: ghost icon (top right of a NEW chat): not saved to memory or history.
- F8 Each project has its own memory (project memory + your normal account memory, not other projects). Turn off **Use account memory** on the project page to fully separate.
- F9 Caution: deleting a chat does NOT delete the memories made from it (delete those separately). Memory is part of data exports.
Anything not on the page is not said (we say "page me nahi likha").
