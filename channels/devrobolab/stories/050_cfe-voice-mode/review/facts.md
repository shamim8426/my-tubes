# Fact check: Claude Feature 06 Short (050), Use voice mode (2026-11-12)
Source (official): https://support.claude.com/en/articles/11101966-use-voice-mode (WebFetch + own Playwright capture, raw/shot_limits.png)
Note: the "styles" help article (planned topic) no longer exists (404), so the topic was switched to voice mode.

| Claim in the video | Official page says | Result |
|---|---|---|
| Click the sound wave icon in the chat box (web/desktop), on phone next to the mic | "click the sound wave icon in the lower-right corner" (web/desktop); "tap the sound wave icon next to the microphone" (mobile) | PASS |
| Choose a voice, then start talking | "Choose a voice to personalize your experience." / "Start speaking to begin your conversation." | PASS |
| Hands-free: Claude answers when you pause (default) | "Claude listens continuously and responds to natural pauses... This is the default mode" | PASS |
| Noisy place: push-to-talk, hold button while speaking | "If you're in a noisy environment ... switch to push-to-talk mode" (hold a button while speaking) | PASS |
| Switch text and voice in one chat, context carries over | "switch between text and voice in the same conversation... context carries over" | PASS |
| Language chosen in Settings, other languages beta | "Settings > Capabilities > Voice > Spoken language"; "Non-English support is in beta" | PASS |
| Voice conversations count toward usage limits | "Voice conversations count toward your regular usage limits" (marked yellow in the video, real crop) | PASS |
| Audio not kept, transcript saved in chat | "By default, audio is not kept... speech is converted to text, recording deleted, transcript saved in chat history" | PASS |

The voice-picker and listening screens (Voice 1/2/3) are our own illustrations, labelled "Illustration (app screens)". The input-box picture is the official page's own screenshot.
