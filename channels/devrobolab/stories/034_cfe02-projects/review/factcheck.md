# Fact-check Claude Feature 02 - Projects (2026-11-06)
Sources (official Claude Help Center): https://support.claude.com/en/articles/9517075-what-are-projects and https://support.claude.com/en/articles/9519177-how-can-i-create-and-manage-projects
PASS - each claim matched by grep on the article text.
| Scene | Claim | Article quote |
|---|---|---|
| hook | A project = own workspace with own chats and knowledge base | "self-contained workspaces with their own chat histories and knowledge bases"; "have focused chats with Claude" |
| create | Projects > + New Project > name and description; Claude cannot see them | 'click "Projects,"'; 'Click "+ New Project"'; "(note that Claude will not have access to these details)" |
| knowledge | Upload documents/text/code; used in all chats of that project | "Upload relevant documents, text files, or code snippets"; "Anything you upload to this space will be used across all of your chats within that project" |
| instr | Set project instructions, Save; applies to all chats of the project | 'Click on "Set project instructions."'; "Claude will use these instructions for all the chats within the project" |
| ctx | Context is not shared between chats unless added to knowledge | "Context is not shared across chats within a project unless the information is added into the project knowledge base" |
| free | Free accounts get projects, max five | "Projects are available to all users, including those with free Claude accounts. Free users can create a maximum of five projects." |
Not claimed: RAG, sharing (Team/Enterprise only), the new beta version of projects, usage/price. Assets: own screenshots of the two articles; real photo 'Abbotsford House Study Room.jpg' (Wikimedia Commons, CC0); AI-drawn robot sticker (labelled in description); diagrams drawn by us.
