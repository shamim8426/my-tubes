# Facts - Claude Code 07 (Platforms). Source only: https://code.claude.com/docs/en/platforms
1. Claude Code runs the same engine everywhere; each surface is tuned for a different way of working - PASS (hook, crop "Where to run Claude Code").
2. CLI: best for terminal workflows, scripting, remote servers; full feature set incl. Agent SDK; "scripting and the Agent SDK are CLI-only" - PASS (crops shown).
3. VS Code: inline diffs, integrated terminal, file context; JetBrains: diff viewer, selection sharing, terminal session; Desktop: visual review, parallel sessions, diff viewer, app preview - PASS (crop rows shown).
4. Web: cloud, Anthropic-managed by default, continues after you disconnect; Mobile: cloud sessions from the Claude app, start and monitor tasks away from your computer - PASS (web row crop highlighted).
5. Integrations: Chrome (controls your browser with your logged-in sessions), GitHub Actions (Claude in your CI pipeline, PR reviews), Slack (@Claude mentions in channels) - PASS (crop shown).
6. Caution: Desktop and the IDE extensions trade some CLI-only features for visual review - PASS (CLI-only crop; script says not every feature is on every surface).
7. Terminal window, `claude -p` example, editor diff and progress bar are illustrations; labelled on screen.
