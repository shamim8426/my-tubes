# Facts (Claude Feature 08: Privacy) - all from official pages, fetched 2026-11-14
Source A: https://privacy.claude.com/en/articles/12109829-how-do-i-change-my-model-improvement-privacy-settings
- Setting "Help Improve our AI models": name menu > Settings > Privacy (claude.ai/settings/data-privacy-controls), toggle off/on. Mobile: same steps.
- Applies to Free, Pro, Max (consumer) and Claude Code on those plans.
- Off: new chats/coding sessions not used for future model training.
- Does NOT undo data already in training that has started, or models already trained.
Source B: https://support.claude.com/en/articles/12260368-use-incognito-chats
- Incognito = temporary chats not saved to history; not added to memory; not used for training; all plans.
- Start: ghost icon upper right; black border + "Incognito chat" label upper left; x to close.
- Kept 30 days by default for safety (org setting longer on Enterprise).
- Only outside Projects (no ghost icon in a project). Cannot be reopened or converted to a regular chat once closed.
