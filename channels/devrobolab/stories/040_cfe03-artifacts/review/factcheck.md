# Fact-check Claude Feature 03 - Artifacts, UI walkthrough version (2026-11-06)
Source (official Claude Help Center): https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them (read 2026-11-06)
The on-screen app is an ILLUSTRATION built only from this article (labelled on every frame). The study-planner text and chat messages are made-up examples.
| Scene | Claim | Article quote |
|---|---|---|
| hook | Claude can make documents, slides, small tools as artifacts | "An artifact is anything Claude makes for you that you'd put in front of someone: a design, a deck, a document, a dashboard, or a small interactive tool." |
| settings | Step 1: Settings > Capabilities > Create and edit files must be on | "Artifacts require Cloud code execution and file creation (called Create and edit files in the updated Settings layout) to be turned on in Settings > Capabilities" |
| create | Step 2: ask in chat; it opens beside the conversation | "Ask for one in any conversation with Claude"; "It opens beside your conversation" |
| edit | Step 3: highlight text, Edit with Claude, type the request; edit happens at the marked place | 'highlight the text you want changed, click "Edit with Claude," and type your request. Claude makes the edit where you marked it' |
| export | Step 4: Docs export to Word, PDF, Markdown, Google Docs | "Docs export to Word, PDF, Markdown, and Google Docs." |
| find | Step 5: all artifacts are in the Artifacts tab in the sidebar | "Everything you make is saved to the Artifacts tab in your Claude sidebar" |
| plans | Chat artifacts on Free; Docs/Slides/Design templates on all plans | Plans table: "Create artifacts in a chat" Free yes; "The Docs, Slides, and Design templates are available on all plans" |
Not claimed: Dashboards/Motion beta, sharing, connected apps, pricing, exact app layout (the real app may differ).
