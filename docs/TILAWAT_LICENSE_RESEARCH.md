Content ID in general: Content ID matches by audio fingerprint, so a reused recitation can be claimed automatically even
with good intent ([Content ID](https://en.wikipedia.org/wiki/Content_ID)). Scholars' views on whether a recitation
is copyrightable differ, but performer / recording rights are widely asserted (e.g. [IslamQA](https://islamqa.org/hanafi/qibla-hanafi/42830/copyrighting-quran-recitation-3/));
the Quran TEXT itself is free.

## Leads (can become "allowed" only with written proof)

   Commons Attribution licence (reuse allowed)" must be visible on the reciter's own official channel. Then: screenshot
   + date in the register. Note it is a live prayer recording (mosque sound, not per ayah).
2. **Aaqib Azeez (row 10).** Ask on Atcovi's Commons talk page (or via the VRT process) whether he is the reciter or has
   the reciter's written permission for CC0. Only a VRT ticket or a written statement makes it "allowed".
3. **King Fahd Complex (row 13).** Email the Complex for its written terms for YouTube (monetized) use.
4. **Local hafiz** — fastest and cleanest: `docs/IJAAZAT_NAMA_TILAWAT.md`. Record ayah by ayah (one file per ayah)
   for easy sync.

## When a source does become allowed

- Download only after the proof is saved (screenshot / email / signed ijaazat-nama scan): keep it in
  `channels/noor-e-raah/research/licenses/` with phone/address blacked out, plus the paper copy.
- Every recording gets one row in `shared/assets_license.csv` (path, source_url, author = qari, license,
  attribution_text, date_added).
- Description: the attribution line. No music under the tilawat (channel decision to confirm).
- If YouTube Studio shows any claim: stop new uploads and tell the user (RULES 10).
